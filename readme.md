# Chipy's Human Interface Device Extension
CHIDE is a script that aims to augment HID experience by packaging together a few commonly used utilities that are all related to HID (things like Mouse and Keyboard)

## Features
### Base
- Update Notification
- Run at Startup toggle
- Custom Hotkey and Settings GUI
### InputRepeater (Auto-Clicker)
- Customizable input (button/key)
- Customizable interval 
- Customizable toggle hotkey 
### MouseBumper (heartbeat)
- Send mouse/keyboard heartbeat signal
- Customizable interval 
- Customizable timeout/self-disable
- Customizable target client
- Customizable toggle hotkey 
### KeyRemapper
- Send mouse/keyboard inputs using alternative keys
- Currently only supports a single remap

## Installation
- Head over to [LastestRelease](https://github.com/iamchipy/chipys-human-interface-device-extension/releases/latest)
- Download and unzip to your desired folder (keep .ico files with EXE)
- Run the EXE
